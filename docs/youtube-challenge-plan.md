> 작성: 2026-07-07 · 상태: **방향 확정** (2026-07-07 결정: 시즌1 인프라 재가동 · **새 Discord 서버** · **롱폼만** 인정) — 잔여 결정은 §7
> 시즌1 "너만·알맡"(2026-03-02~05-23, 12주) 구조를 복제하되, 운영하며 드러난 시행착오를 반영해 유튜브 단일 플랫폼 챌린지로 재기획한다.

### 시즌1과의 철학 차이
시즌1 슬로건 "너 만들기만하고, 알고리즘에 맡겨"는 유지하되, 규칙을 **더 좁고 더 명확하게** 바꾼다.
시즌1의 "최소 2주 1회, 플랫폼 자유"는 유연했지만 그만큼 리듬이 무너지기 쉬웠다.
시즌2는 "매주 1개, 유튜브만" — 규칙이 하나뿐이라 판정 논쟁이 생길 수 없다.

## 2. 규칙 (전부 3줄)

1. **매주(월 00:00 ~ 일 24:00 KST) 유튜브 영상 1개를 공개 업로드하고, 그 주가 끝나기 전에 Discord `/인증`으로 URL을 제출한다.**
2. 주 2개 올려도 인정은 1개 — 몰아찍기 방지, "매주 찍는 근육"이 목표.
3. 미인증 주는 실패로 기록하고 다음 주 초 정산 카드에 표시된다 (개별 DM 안내 아님 — 2인이라 서로 다 보임).

- 인정 범위: **롱폼만** (확정 2026-07-07). 판정 기준: `youtube.com/shorts/` URL은 인증 거부, 일반 `watch`/`youtu.be` URL만 인정. 영상 길이 API 검사는 MVP에서 제외(상호 신뢰 + URL 패턴으로 충분).
- 실패 페널티(벌금·커피 등): **결정 필요** — §7

### 유튜브 전용 신규 개선 (시즌1에 없던 것)
- **정산 카드에 성과 지표**: 주간 정산 시 각 영상의 조회수·좋아요를 YouTube Data API(무료 쿼터 충분)로 가져와 카드에 표시 — "알고리즘에 맡겨"의 결과를 실제로 보는 루프. (선택 기능, MVP에선 제외 가능)
- **스트릭 표시**: 🔥 연속 N주 — 정산 카드와 갤러리 양쪽.
