CHALLENGE PROPOSAL · 2026-07

유튜브 챌린지 제안서
매주, 딱 1개.

"너 만들기만하고, 알고리즘에 맡겨" — 지난 12주 콘텐츠 챌린지의 검증된 운영 구조를 그대로 물려받고, 시행착오를 손본 유튜브 전용 시즌입니다.

제안: 임정 → 슬기님 · 2026-07-07

01왜 다시, 왜 유튜브인가

지난 시즌은 "최소 2주에 1회, 플랫폼 자유"였습니다. 유연했지만 그만큼 제작 리듬이 무너지기 쉬웠습니다. 이번 시즌은 규칙을 하나로 줄입니다 — 판정 논쟁이 생길 수 없을 만큼 좁고 명확하게.

매주 유튜브 롱폼 영상 1개를 공개 업로드한다. 더도 말고 덜도 말고 1개. 목표는 조회수가 아니라 "매주 찍는 근육"입니다.

02규칙 — 전부 세 줄

1

매주(월 00:00 ~ 일 24:00 KST) 롱폼 1개를 공개 업로드하고, 그 주가 끝나기 전에 Discord /인증으로 URL을 제출합니다. 쇼츠는 인정하지 않습니다.

2

주 2개를 올려도 인정은 1개. 몰아찍기 방지 — 리듬이 목표이기 때문입니다.

3

미인증 주는 실패로 기록되고 다음 주 초 정산 카드에 표시됩니다. 개별 안내 없음 — 둘 뿐이라 서로 다 보입니다.

03일정 — 준비 1주 + 발행 12주

준비
1주
발행 12주 — 매주 1개, 총 12개
07-07 (월) 07-13 (월) 발행 시작 10-04 (일) 종료

준비기간에는 채널 방향·소재 리스트를 정리하고, 리허설 인증을 각 1회 해봅니다. 시작일은 협의 가능합니다.

04운영 시스템 — 사람이 안 챙겨도 돌아가게

지난 시즌 12주를 실제로 굴린 자동화를 그대로 씁니다. 참가자가 하는 일은 업로드하고, 링크 한 번 제출하는 것뿐입니다.

인증전용 Discord 서버에서 /인증 입력 → 링크 제출 → 봇이 자동으로 영상 정보를 읽어 기록. 쇼츠·타 플랫폼 URL은 자동 거부
주간 정산매주 월요일 아침, 지난주 결과 카드가 자동 게시 — ✅ 달성 / ❌ 미달성 + 🔥 연속 주차 스트릭
갤러리제출한 영상이 쌓이는 공개 웹 갤러리 — 12주 뒤 우리 둘의 아카이브가 됩니다
스트릭메달·순위 대신 연속 달성 주차(🔥 N주)를 추적 — 2인 챌린지에 맞는 동기부여

05지난 시즌에서 배운 것 → 이번에 바꾼 것

지난 시즌이번 시즌
최소 2주 1회, 플랫폼 자유 — 리듬 유지 어려움규칙매주 1개, 유튜브만. 규칙이 하나라 애매함 제로
플랫폼별 링크 수집이 종종 불안정안정성유튜브 단일화로 인증 실패 요인 원천 제거
순위·메달 중심 — 소수 인원에겐 동기부여 약함동기나 자신과의 연속 기록(스트릭) 중심
기능이 많아 운영 부담 존재단순화인증·정산·갤러리 3가지만 남기고 다이어트

06함께 정하면 좋은 것

① 시작일 — 7/13(월) 제안. 다음 주가 어렵다면 7/20도 가능
② 실패했을 때 — 없음 / 커피 사기 / 다음 영상 소재 결정권 넘기기 중 택 1 (개인적으론 "가시성만으로 충분하다"에 한 표)
③ 조회수 리포트 — 주간 정산에 각 영상 조회수·좋아요 표시 여부 (알고리즘에 맡긴 결과를 눈으로 보는 재미 vs 숫자 스트레스)
